# Wolmar — мониторинг монетных аукционов

Инструменты для отслеживания лотов на аукционах [wolmar.ru](https://www.wolmar.ru/): парсинг текущих и прошедших аукционов, сбор истории цен и фильтрация лотов по заданному списку монет.

## Состав проекта

| Файл | Назначение |
|---|---|
| `mparser.pl` | Основной парсер. Скачивает текущие аукционы VIP и Standart (секции «Монеты России до 1917 — серебро», «— медь», «Монеты РСФСР/СССР/России»), фильтрует лоты по `coins_config.json` и формирует HTML-отчёт `au<ID>.html` |
| `numizmatik_vip.pl` | Парсер VIP-распродажи магазина numizmatik.ru. Берёт ссылку из письма (Gmail IMAP) или из `--url`, фильтрует товары по тому же `coins_config.json` и формирует HTML-отчёт `numizmatik_vip.html` |
| `numizmatik_vip.conf.json.example` | Пример конфигурации IMAP для `numizmatik_vip.pl` (скопировать в `numizmatik_vip.conf.json` и вписать пароль приложения) |
| `stats_builder.pl` | Собирает историю цен по прошедшим аукционам в базу `coins_stats.db` (SQLite) |
| `coin_editor_server.pl` | Веб-редактор конфига `coins_config.json` с автоматическим открытием в браузере |
| `coins_config.json` | Список известных монет: годы, чеканки и значения для фильтрации |
| `coins_stats.db` | База истории цен (создаётся `stats_builder.pl`) |
| `install.sh` | Установка Perl-зависимостей через `cpanm` |
| `au<ID>.html` | Сгенерированные отчёты по аукционам |

## Установка

Требуется Perl и `cpanm`:

```bash
./install.sh
```

## Использование

### Сбор статистики по прошедшим аукционам (один раз, для истории цен)

```bash
# первичное заполнение базы
perl stats_builder.pl --init --count 20

# обновление (добавляет новые прошедшие аукционы)
perl stats_builder.pl --count 20
```

Опции: `--init` — создать базу заново, `--count N` — сколько аукционов VIP и Standart обработать (по умолчанию 20), `--noverbose` — тихий режим.

### Генерация отчёта по текущим аукционам

```bash
perl mparser.pl
```

При запуске без аргументов берутся текущие аукционы VIP и Standart с главной страницы, результат — файл `au<ID>.html`. Можно указать конкретный аукцион:

```bash
perl mparser.pl 2233
```

### Редактирование конфига монет

```bash
perl coin_editor_server.pl        # порт по умолчанию 8081
perl coin_editor_server.pl 9000   # другой порт
```

Открывается в браузере автоматически. Изменения сохраняются напрямую в `coins_config.json`.

### Парсинг VIP-распродажи numizmatik.ru

Скрипт `numizmatik_vip.pl` обрабатывает страницу распродажи магазина «Клуб Нумизмат» (ссылка приходит в письме) и ищет монеты по тому же `coins_config.json`, что и `mparser.pl`.

Два режима:

```bash
# 1. По ссылке из письма (вручную)
perl numizmatik_vip.pl --url "https://www.numizmatik.ru/shopcoins/?page=viporder&id=...&sing=..."

# 2. Автоматически — взять ссылку из последнего письма на Gmail
cp numizmatik_vip.conf.json.example numizmatik_vip.conf.json
# вписать username и password (пароль приложения Gmail) в numizmatik_vip.conf.json
perl numizmatik_vip.pl --email
```

Опции:

| Опция | Описание |
|---|---|
| `--url URL` | Ссылка на страницу VIP-распродажи |
| `--email` | Взять ссылки из писем (нужен `numizmatik_vip.conf.json`) |
| `--count N` | Сколько последних писем обработать (по умолчанию 1) |
| `--config FILE` | Альтернативный конфиг IMAP |
| `--output FILE` | Имя выходного HTML-файла (по умолчанию `numizmatik_vip.html`) |
| `--no-open` | Не открывать отчёт в браузере |
| `--verbose` / `--no-verbose` | Подробный / тихий вывод |

Отчёт содержит две таблицы: **подходящие монеты** (прошли фильтр `coins_config.json` по году, чеканке, цене и состоянию) и **близкие совпадения** (монеты из конфига, но дороже ценового порога или в высокой сохранности — с указанием причины).

Для режима `--email` нужен **пароль приложения** Gmail (не основной пароль): Google-аккаунт → Безопасность → Двухэтапная аутентификация → Пароли приложений.

Для автозапуска по будням можно добавить в crontab, например (по будням в 09:30):

```cron
30 9 * * 1-5 cd /path/to/wolmar && perl -Ilocal/lib/perl5 numizmatik_vip.pl --email --no-open >> numizmatik_vip.log 2>&1
```

## Управление конфигом монет

Интерфейс `coin_editor_server.pl` работает с файлом `coins_config.json`. В нём четыре вкладки (секции):

| Вкладка | Тип данных | Описание |
|---|---|---|
| Серебро империи | `year_mint` | Монеты Российской империи (серебро), разбивка по годам и чеканкам |
| Медь империи | `year_mint` | Монеты Российской империи (медь), разбивка по годам и чеканкам |
| СССР/Россия обычные | `year_mint` | Обычные монеты СССР и современной России |
| Памятные монеты | `key_value` | Памятные и юбилейные монеты (название → значение) |

### Строки в секциях `year_mint`

Каждая строка таблицы — это **один год конкретной монеты**. У одной монеты может быть много строк (по году):

- **Название** — номинал монеты, например `2 копейки`.
- **Год** — год выпуска.
- **Чеканка** — значение для фильтрации: конкретная чеканка (`СПБ`, `ЕМ`) или `-` (любая чеканка).
- **Акт.** — галочка активности.
  - Включена: год участвует в поиске, значение чеканки используется.
  - Выключена: значение сохраняется как `null`, год не участвует в поиске, но остаётся в конфиге.

### Строки в секции `commemorative`

Каждая строка — одна памятная монета:

- **Название** — полное название монеты.
- **Год / Значение** — год выпуска или другое значение для фильтрации.
- **Акт.** — активность монеты.

### Кнопки

- **Сохранить** — записывает текущее состояние всех вкладок обратно в `coins_config.json`. Перед записью JSON валидируется.
- **Добавить монету** — добавляет новую монету. Для `year_mint` появится запрос названия; если монета уже существует, добавится пустой год к ней. Для `commemorative` добавляется новая запись, дубли по названию запрещены.
- **×** в строке — удаляет строку:
  - В `year_mint` удаляется **конкретный год** монеты. Если у монеты не остаётся годов, запись монеты удаляется целиком.
  - В `commemorative` удаляется монета целиком.

### Важно: отключение vs удаление

- Чтобы **временно исключить** год или монету из поиска — снимите галочку **Акт.**.
- Чтобы **полностью удалить** год или монету — нажмите **×**.

### Формат конфига coins_config.json

```json
{
  "imperial_silver": {
    "5 копеек": { "1858": "-", "1878": "СПБ НI" }
  },
  "imperial_copper": {},
  "ussr_russia_regular": {
    "10 копеек": { "1925": "-" }
  },
  "commemorative": {
    "3 рубля. Форт Росс": "-"
  },
  "notes": {
    "imperial_silver": [],
    "imperial_copper": [],
    "commemorative": []
  }
}
```

- `imperial_silver`, `imperial_copper`, `ussr_russia_regular` — монеты с разбивкой по годам; значение — чеканка (или `"-"`).
- `commemorative` — памятные монеты: название → значение.
- Значение `null` — позиция временно отключена и не участвует в фильтрации поиска.
- `notes` — текстовые заметки по секциям (не используются парсером, только для справки).
